# AuraVision — XREAL Aura (70° FOV / Android XR) WebXR パススルーシミュレーター

Meta Quest (Quest 3 / 3S / Pro 等) のフルカラーパススルー (`immersive-ar`) を利用し、Google の **Android XR** 搭載光学シースルーグラス **XREAL Aura (Project Aura)** の視界（対角 70° FOV・アスペクト比 16:10・5段階エレクトロクロミック調光）を実寸角度で体験・検証するための WebXR コンテンツです。

---

## 主な機能

1. **実寸角度による光学プリズム FOV クリッピング（頭部追従）**
   - 頭部に追従する光学プリズム枠（`THREE.Plane` による 4面ワールド空間クリッピング）を実装。
   - 空間に固定された仮想ウインドウ（6DoF）に対して頭を動かすと、**対角 70°（水平 61.4° × 垂直 40.7° / 16:10）のプリズム領域内のみに仮想映像が表示**され、その外側は現実のパススルー視界のみが見える光学シースルーグラス特有の見え方を忠実に再現します。

2. **歴代 XREAL モデルとのリアルタイム FOV 比較**
   - **XREAL Air / Air 2**: 対角 46° (16:9 / 水平 40.6° × 垂直 23.5°)
   - **XREAL Air 2 Ultra**: 対角 52° (16:9 / 水平 46.1° × 垂直 27.0°)
   - **XREAL One Pro**: 対角 57° (16:9 / 水平 50.8° × 垂直 29.9°)
   - **XREAL Aura**: 対角 70° (16:10 / 水平 61.4° × 垂直 40.7° — Air比で約2.3倍の表示面積)
   - **比較枠の重ね表示モード**: 46° / 52° / 57° / 70° の視野枠を同時に重ねてサイズ差を一目で比較可能。

3. **5段階エレクトロクロミック調光（Dimmer）＆グラスフレーム再現**
   - 外側のサングラスレンズ領域（約96°×56°）の透過率を **Lv.1 (10% クリア) 〜 Lv.5 (98% 没入モード)** の5段階で切り替え可能。
   - フレーム外周および鼻元の隙間からは調光なしの現実空間が見えるため、実際のグラス装着感に近いコントラスト変化を確認できます。

4. **Android XR 風 空間マルチウインドウ UI**
   - **中央ウインドウ (Spatial Cinema & 視野角アナライザー)**: 85" / 115" / 150" / 190" の画面サイズ切り替えと、現在の画面がアクティブな FOV 内に収まっているかをリアルタイム判定。
   - **左ウインドウ (Gemini Live & Google Maps AR)**: 16:10 の縦方向余裕（1920×1200）を活かした空間ナビ・AIアシスタントカード。
   - **右ウインドウ (FOV 面積・PPD 比較インスペクタ)**: 歴代モデルとの面積比・視野角の視覚的チャート。
   - **下部 3D コントロールドック**: Quest 内でレーザーポインターやハンドトラッキング（ピンチ）を使って、すべての設定を直接切り替え可能。各ウインドウ下の白バーを掴んで 3D 空間内の好きな位置へ移動することもできます。

## Meta Quest で確認する方法

WebXR API はセキュリティ仕様上 **`https://`** または **`http://localhost`** でのみ有効になります。以下のいずれかの方法で Meta Quest Browser から開いてください。

### 方法A: USB接続 + `adb reverse`（証明書不要・最速）
1. PC で任意のローカルサーバーを起動します（例: Python または Node.js）:
   ```powershell
   python -m http.server 8080
   # または
   npx serve -l 8080
   ```
2. Meta Quest を USB で PC に接続し、以下を実行します:
   ```powershell
   adb reverse tcp:8080 tcp:8080
   ```
3. Meta Quest 内のブラウザで **`http://localhost:8080`** を開きます。
4. **「🥽 Meta Quest パススルー (AR) を開始」** ボタンを押すとパススルー AR セッションが開始されます。

### 方法B: GitHub Pages / Vercel / Cloudflare Pages にホスティング
ビルド不要な静的構成（`index.html` + ES Modules）のため、そのままリポジトリを GitHub Pages 等に公開するだけで `https://` URL から Meta Quest Browser でアクセスできます。

## 操作方法

### Meta Quest (AR パススルー中)
- **トリガー / ハンドピンチ**: 3D ドックやウインドウ内のボタンをクリック
- **ウインドウ下の白バーをトリガー/ピンチでドラッグ**: ウインドウを 3D 空間内で移動
- **A ボタン / X ボタン**: FOV モデル切り替え (`46°` → `52°` → `57°` → `70°` → `制限なし`)
- **B ボタン / Y ボタン**: 5段階エレクトロクロミック調光切り替え (`Lv.1` 〜 `Lv.5`)
- **グリップボタン**: 現在の正面方向にワークスペースを再配置（リセット）

### PC ブラウザ (デスクトップ・シミュレーターモード)
- **マウス左ドラッグ**: 首振り（頭部に追従する 70° 光学プリズム枠で空間ウインドウがクリッピングされる様子を確認）
- **ウインドウ内クリック**: 3D UI ボタンの操作
- **`1` 〜 `5` キー**: FOV モデル切り替え
- **`D` キー**: 5段階調光切り替え
- **`C` キー**: 歴代 FOV 比較枠の重ね表示 ON/OFF
- **`G` キー**: 10° 刻み視野角ルーラー ON/OFF
- **`R` キー**: 正面リセット
